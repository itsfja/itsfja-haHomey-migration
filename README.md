# haHomey-migration 🐞

Home Assistant → Homey migration plan, Ladybird-book style.

- Full guide: [MIGRATION.md](MIGRATION.md)
- Source: inventoried live from the Home Assistant instance (1,304 entities, 2 automations) and the Homey account (Homey Bridge, 19 zones, 0 flows).

## TL;DR
- Buy a **Homey Pro** (Early 2023) — the Bridge alone won't cut it.
- Migrate: smart plugs, Zigbee/Z-Wave re-pair, Sonos, TVs, Powerwall + Octopus Cosy, Vaillant, cameras, presence.
- Keep on HA / elsewhere: server-room monitoring, Node-RED, ESPresense/Bermuda BLE, local voice stack.
- Appendix A of the guide lists exactly what ain't happening.
